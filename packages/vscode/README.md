# @tsfx/extension

VSCode extension for the TSFX monorepo.

## Getting Started

1. Install dependencies: `pnpm install`
2. Open this folder in VSCode: `code packages/extension`
3. Press `F5` to launch the Extension Development Host.
4. Run the `TSFX: Hello World` command from the Command Palette (`Ctrl+Shift+P`).

## Build

- `pnpm run build` — compile TypeScript
- `pnpm run watch` — compile in watch mode
- `pnpm run lint` — run Biome
